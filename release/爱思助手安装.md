# 用爱思助手装到 iPhone 15 Pro Max（¥0 路线）

**先说结论：ipa 文件我在这台 Windows 上生成不出来，但整条路线是通的，而且一分钱不花。**

---

## 一、为什么我不能直接给你一个「用爱思装的安装包」

不是懒，是中间有两道门槛绕不过去：

| 门槛 | 说明 | 谁能过 |
|---|---|---|
| **编译** | Swift 源码 → App（内含 ARM 二进制），只能用苹果的 Xcode 工具链，而 Xcode 只跑在 macOS 上 | 任何一台 Mac，**包括云上的** |
| **签名** | 苹果规定 App 必须有合法签名才允许安装，否则手机上「无法验证 App」 | 你自己的 Apple ID（免费）或付费证书 |

**爱思助手解决的是第二道**（签名 + 安装），**它不解决第一道** —— 它不是编译器，没法把 `.swift` 变成 App。它需要一个 `.ipa` 文件作为输入。

所以流程是：

```
源码（我已经写好）
   ↓   云 Mac 编译        ← GitHub Actions，公开仓库免费无限
未签名 ipa
   ↓   你电脑下载
爱思助手 + 你的 Apple ID   ← 免费，7 天有效期
   ↓
iPhone 15 Pro Max
```

**唯一代价：7 天过期，需要重装一次。** 重装不用重编译，ipa 还在你电脑上，爱思点几下的事。

## 三、具体步骤

### 第 1 步（一次性）：把代码传到 GitHub

⚠️ **仓库根目录 = `bk-clip` 文件夹「里面」的内容**。
不要把 `bk-clip` 当成子目录整个塞进仓库 —— 那样 GitHub 扫不到工作流文件，Actions 页面会是空的，
你会以为没开通成功，其实是目录放错了一层。

仓库可见性选 **Public**：公开仓库上 macOS 云主机免费无限。
具体怎么注册、怎么传，见同目录下的 `开通GitHub云编译.md`。

> Public ≠ 商业发布。这只是你自己用的一个剪辑小工具，公开只是为了换免费云编译。

### 第 2 步：云端编译成未签名 ipa

1. 打开仓库页面 → **Actions** 标签
2. 左侧选「打包未签名 IPA」
3. 右边点 **Run workflow** → 绿色按钮确认
4. 等 6~10 分钟，跑完在页面最下方的 **Artifacts** 区域出现 `bkClip-unsigned-ipa`
5. 点它下载，解压得到 `bkClip-unsigned.ipa`

> 工作流文件已经写好在 `.github/workflows/build-unsigned-ipa.yml`，不用你动。
> 以后改了代码，重跑一次 workflow 就有新包。

### 第 3 步：爱思助手签名

1. 电脑装爱思助手（**i4.cn** 官网，别从第三方下载站）
2. iPhone 用数据线连上电脑，**解锁屏幕、点「信任此电脑」**
3. 工具箱 → **IPA 签名**（有的版本叫「IPA 文件签名」）
4. 选「**使用 Apple ID 签名 - 添加 Apple ID**」
   - 输入你的 Apple ID 和密码
   - ⚠️ **如果 Apple ID 是手机号，前面要加 86**，例如 `8613812345678`
   - 开启双重认证的账号，如果反复验证失败，去 appleid.apple.com 生成一个专用密码再试
5. 点「添加 IPA 文件」，选刚才下载的 `bkClip-unsigned.ipa`
6. 勾选文件和账号 → **开始签名**
7. 签名完成后点「打开」找到签名好的文件（**注意：签名后的文件和原文件不在同一个目录**）
8. 拖进爱思主界面安装到手机

### 第 4 步：手机上信任

首次打开 App 前，去 **设置 → 通用 → VPN与设备管理**（老版本叫「描述文件」），
在「开发者 App」下面找到你的 Apple ID，**点信任**。

这一步漏了的结果就是：App 图标正常，点开弹「未受信任的企业级开发者」，然后再也打不开。

## 四、7 天到期之后

到期表现：App 图标变灰，或者直接打不开。

**正确做法：到期前用爱思重新签一次，在旧 App 上覆盖安装，草稿还在。**
覆盖安装会保留沙盒数据，所以你连工程都不用重新做。

**千万别删掉旧的再装新的** —— 删了 App，沙盒就跟着一起清了，草稿是真的没了。

> 这一点我会在下一批代码里做个保险：加一个「导出草稿」按钮，把工程 JSON 存成文件分享出来。到时候就算重装也不怕。

## 五、排错表

| 症状 | 原因 | 怎么办 |
|---|---|---|
| **签名失败，错误码 45** | IPA 包内部路径含中文 | 我已经在项目里规避了：包名强制 `BKClip`，中文只出现在显示名上。别改回去 |
| **签名失败，错误码 44** | 包架构损坏 | 重新从 GitHub 下载原始包，别用改过的 |
| Apple ID 报错 `-20101` / `-22406` | 账号或密码输错 | 手机号前加 86；或改用专用密码 |
| 装完打不开，提示未受信任 | 没在设置里信任 | 设置 → 通用 → VPN与设备管理 → 信任你的 Apple ID |
| Actions 找不到 workflow | 分支不对 | 文件必须在**默认分支**上，GitHub 才显示 Actions |
| 编译报 signing 错误 | 不该签名却签了 | workflow 里已经强制 `CODE_SIGNING_ALLOWED=NO`，别删那几行 |
| 爱思提示签名要开会员 | 部分版本的收费策略 | 换 AltStore / SideStore 走同样的流程，效果一样 |

## 六、现在动手之前，先看清一件事

这条链路里**唯一还没跑通的一环，是「云上能不能编译成功」**。

代码我写完了，但还没有在任何一台 Mac 上编译过 —— 语法错、API 用错、Frameworks 漏了，都可能让第 2 步红掉。这是正常的，第一次编译基本没有一次过的。

到时候的处理方式很简单：**把红色报错信息整段发我，我来改。** 这比你现在猜省钱多了。

建议时机：把手头这段素材的活做完再弄，别在拍摄旺季为这事分心。
