定版基线 · 交互说明

编辑页：点任意轨道的任意区块 → 三轨同步滚动使该区块中心对齐固定在可视区中央的白色指针 → 该区块出现品牌蓝框 + 时长标签 → 悬浮菜单弹出（水平以指针为参照居中，垂直紧贴所点轨道上方 6pt，图标+文字）。点菜单之外的空白处即关闭菜单。
悬浮菜单按轨道切换内容：主轨 = 替换/波剪/上锁/复制/删除；画中画 = 替换/切开/上锁/复制/删除；录音 = 切开/音量/上锁/复制/删除。
两条素材流程：替换 = 素材库 → 预览 → 片段选择（时长锁定为被替换片段时长）→ 完成；插入 = 选视频 → 截取 → ✓ 插到指针处区块之前。两者都只换 src 或插入新段，不改已有片段时长。
红区只在波剪页：编辑页主轨与迷你条均为中性色（无红罩/无折叠线）；红绿气口标记仅在「波形剪辑」页表达。
导出：顶栏 ⬆ 或底部工具栏「导出」均可唤起导出抽屉（首帧缩略图 / 仅导出音频 / 分辨率 / 帧率 / 预计大小 / 导出）。
底部工具栏：纯线条图标、无文字、横滑，分 4 组（剪辑 / 媒体 / 调节 / 系统），选中项底部蓝条高亮；「波剪」「导出」「调节」为可跳转的真实功能。
顶部 9 个页面切换按钮仅供演示聚焦，真实产品中不存在。
