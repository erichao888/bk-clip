## 差异化约束（避免与竞品雷同，2026-10-04 评估结论）

**目的**：借鉴交互范式，但成品视觉表达必须与竞品拉开距离，避免被指「实质性相似」。
- **可放心借鉴（属「必要场景」/行业通用，不受保护）**：
  底栏工具栏、轨道时间线、播放头、选区上下文工具、添加行占位等**功能布局与交互范式**。
  这些是所有剪辑 App（剪映/必剪/快影/VN/InShot）共享的通用范式。
- **必须规避的表达层（对方可能保护）**：
  ①琥珀色悬浮工具条（黄底白圆钮）的**精确外观**　②具体图标造型
  ③其专属配色与字号体系　④对方若已注册的 GUI **外观设计专利**元素　⑤任何插画/吉祥物/专属动效。
- **我方天然差异点（已在设计中确立）**：
  声音包络线红绿标记+折叠模型（**概念独创**）｜SF Symbols **单线条图标**（非对方填充色图标）
  ｜底部工具栏**可横滑**｜红绿切换=独立按钮（非点选切换）｜折叠线宽=指针宽（独创视觉）。
- **落地清单**：选色改用 BKTheme 品牌色而非琥珀色；悬浮条改形状/位置（如锚定片段下方或左侧）；
  图标维持线条风；**不复制**对方任何插画/吉祥物/动效。
- **总原则**：抄「思想」（编辑器怎么摆），不抄「表达」（对方的像素与美术）。

### 悬浮工具条配色定稿（2026-10-04 23:35 皓哥拍板）

- **蓝底胶囊 + 线条按钮**，主色取自皓哥提供的参考图：**`#2F6DF4` = RGB(47, 109, 244) = HSB(221°, 81%, 96%)**。
- 与竞品区分：对方是「琥珀黄胶囊 + 白圆钮 + 填充图标」，我们是「蓝胶囊 + 线条图标直绘」，色/形/图标三重差异。
- 归属：颜色只进 **BKTheme**（唯一实现归属原则），建议 `static let accent = #2F6DF4`。
- 选中态黄框是否同步改蓝：待定（皓哥确认）。若选区框仍用黄，则「黄=选中、蓝=操作」双色语义也成立。
