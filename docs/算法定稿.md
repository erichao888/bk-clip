## 0. 三条方向原则（决定一切参数取值）

皓哥 2026-10-02 晚逐条回答的，这个口径是**激进优先**：

| # | 皓哥的回答 |
|---|---|
| 1 | 片头片尾的安静段 **切掉** |
| 2 | 0.1~0.25 秒的短换气 **切** |
| 3 | 整体轻声区（跟周围比只差 3~10dB）**也切** |

**总原则：宁多勿少。** 误切的用 ⟳ 反选 / 拖手动把手补回来，
但漏切的要靠人一句一句找，代价大得多。任何「怕切错」的保护参数都要为它让路。

## 1. 参数表（改这里 = 改 App）

| 参数 | 旧值 | **定稿值** | 说明 |
|---|---|---|---|
| `MIN_GAP` | 0.20 | **0.10** | 低于 0.1s 的低幅基本是音节内瞬态，碰了会把字切碎 |
| `MIN_SEG` | 0.60 | **0.30** | 旧值 0.6 是 4582/4583 一刀不切的元凶 |
| `MIN_CUT` | 0.10 | **0.04** | 0.04s = 40ms，双 15ms 交叉淡入淡出还盖得住 |
| `PAD` | 0.10 | **0.03** | **只收贴语音那一侧**，片头片尾不收（从 0 帧切起） |
| `CONTRAST_DB` | 6.0 | **0.0** | 「轻声区也切」之后这关卡没有判别力，归零待命 |
| `CLAMP_LOW/HIGH` | −50 / −25 | 不变 | Otsu 结果夹逼区间 |
| `FRAME_MS / HOP_MS / SR` | 20 / 10 / 16k | 不变 | 粒度本来就够细 |

## 2. 处理管线（顺序不能变）

```
① 抽单声道 PCM（16kHz，不用原始 48k）
② 20ms 窗 / 10ms 步进 算 RMS 包络 → 转 dB
③ Otsu 自动阈值，夹逼到 [-50, -25]
④ 低于阈值 → 候选气口，**片头片尾的不再跳过**
⑤ 去掉贴语音那侧的 PAD（头尾段不收）
⑥ 保留片段短于 MIN_SEG → 相邻两刀合并 / 首刀扩到 0 / 末刀扩到片尾
⑦ 局部对比度过滤（CONTRAST_DB=0，等于不设防）
⑧ 导出：保留片段拼接 + 接缝 15ms 淡入淡出
```

## 3. 实测数据（四条样片，旧 → 新）

| 素材 | 时长 | 旧算法 | **定稿算法** |
|---|---|---|---|
| IMG_4580 | 16.64s | 6 刀，删 13.7% | **8 刀，删 30.4%** |
| IMG_4582 | 7.91s | **0 刀** | **5 刀，删 36.6%** |
| IMG_4583 | 4.73s | **0 刀** | **5 刀，删 28.9%** |
| IMG_4990 | 15.49s | 4 刀，删 21.4% | **7 刀，删 44.2%** |

**真实气口的数据特征**（普查得来，供以后调参参考）：

- 说话段和真气口**分离得很开**，中间气口深度普遍 **20~30dB**
- 只有「整段话越来越轻」的尾部是 3~10dB —— 皓哥照样要切
- 旧算法把 0.16 / 0.21 / 0.11 / 0.26 / 0.19s 这类又短又深的气口全丢了，是欠切主因

## 4. 实现时防着点（Python 侧钓出来的真 bug）

1. **段和刀的编号会错位**：`kept_segments` 会过滤零宽/重叠段，
   一过滤，「第 N 段」跟「第 N 刀」就对不上了，合并逻辑拿着错位编号去并刀，越并越乱。
   → 判短必须用**不过滤**的对齐视图（`_segs_aligned`），判完再清零宽
2. **零宽段不能参与「太短」判断**：首刀起点扩到 0 之后该段变成 (0, 0)，
   再判短就是原地打转，循环空转到上限退出，短片段根本没被收拾。
   → 判短条件必须是 `1e-6 < 段长 < MIN_SEG`

---

## 5. 已知边界（不是 bug，是原理限制）

- **带 BGM / 做过响度归一化的成品**从原理上不适用静音检测 —— 底噪被抬起来了，没有真正的安静段
- **有声废话**（"嗯——""那个那个"）只要音量不低，静音检测抓不到。
  只能靠 ⟳ 反选手动补刀，这也是那个按钮存在的意义
- 本机语音识别那条路（faster-whisper 拉不下模型）不通，别再试
