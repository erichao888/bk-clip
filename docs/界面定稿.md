## 0. 一句话定位

探店口播视频的**去气口工具**：导入一段（或多段）视频 → 自动找出「嗯、啊、停顿」并标记 → 手动微调 → 导出成品。

不是通用剪辑器。不做转场、滤镜、字幕、配乐、调速。

## 1. 全局约定

### 1.1 配色焊死，不跟系统深浅模式

**这是踩过坑的地方**： BKTheme 原本做了 light/dark 两套，皓哥手机开深色模式，
结果看到的是暗色版波形 —— 而参考图定的是**浅色系**。剪辑软件要「颜色稳定可预期」，
白天黑夜一个样（剪映同理）。所以：

**全 App 一律用下面这套固定色值，不再用 `UIColor.bk(light:dark:)` 动态色。**

| 用途 | 色值 | 备注 |
|---|---|---|
| 页面底 | `#F7F7F4` | 浅白 |
| 工具栏底 | `#F1F1EE` | 比页面底略深一点 |
| 主轨道底 | `#C7D8BD` | 浅绿 |
| 波形本体 | `#24430F` | 深绿，实心 |
| 待删气口 | `#D6707A` @60% | 粉红半透明 |
| 气口边界线 | `#D6707A` | 实心 |
| 边界把手 | `#FFFFFF` | 小白条，4×8pt |
| 指针 | `#F09A28` | 橙，竖线 2pt + 顶部倒三角 |
| 阈值虚线 | `#EF9F27` | 黄，虚线 |
| 概览条底 | `#8F9389` | 灰 |
| 概览条波形 | `#4C5049` | 深灰 |
| 视窗框 | `#F09A28` | 橙描边 |
| 预览区 | `#141414` | 画面本身是黑底，不染 |
| 按钮底 | `#FFFFFF` | 白圆 + `#D1D1D6` 细描边 |
| 按钮线条 | `#1A1A1A` | 黑 |
| 正文文字 | `#1A1A1A` | |
| 次要文字 | `#5F5E5A` | |

### 1.2 按钮样式

- **一律单线条图标，不要文字**（皓哥明确要求，推翻更早的「不用图标」偏好）
- 白圆底 + 1px `#D1D1D6` 描边，直径 **44pt**（苹果最小可点区）
- 图标线条 1.6~1.8px 黑色，全部用 **SF Symbols**
- **唯一例外**：导出按钮是图标 + 文字（这个按钮按下去不可逆，认错代价太大）

### 1.3 只做竖屏

不跟随手机旋转，不支持横屏。

## 4. 编辑页（核心）

```
┌────────────────────────────────────┐
│ ☰  IMG_2969.MOV              导出  │  ← 导航栏
├────────────────────────────────────┤
│ ↩ ↪ │ − ●── + │ ■ ▶ ⟳ ✂ 💉 │ 00:12 │  ← 工具栏
├────────────────────────────────────┤
│                                    │
│         视频画面（9:16）            │  ← 跟随指针跳帧
│                                    │
├────────────────────────────────────┤
│  主轨道：浅绿底 / 深绿波形 / 粉红气口 │
│  橙色指针钉死正中央，内容在底下滚     │
├────────────────────────────────────┤
│  概览条：灰底小波形 + 橙色视窗框      │
├────────────────────────────────────┤
│ 阈值 -37.5  ──────●────            │
│ 原 00:42 · 剪后 00:38 · 7刀 · 3.2s  │
└────────────────────────────────────┘
```

### 4.1 导航栏

| 位置 | 元素 | 行为 |
|---|---|---|
| 左 | ☰ 三条横线 | 打开/收起素材列表（素材 >1 条才可用） |
| 中 | 文件名 | 只读 |
| 右 | 导出（图标+文字） | 导出当前这条 |

素材列表：展开为**固定 5 行**的可滚动窗口（不撑开页面），当前条金色 + ✓，点名字切换素材。

### 4.2 工具栏（从左到右）

| 图标 | 名称 | SF Symbol | 行为 |
|---|---|---|---|
| ↩ | 撤销 | arrow.uturn.backward | 撤销上一步编辑 |
| ↪ | 重做 | arrow.uturn.forward | 重做 |
| − ● + | 缩放滑杆 | — | 横向缩放轨道（1~20 屏） |
| ■ | 停止 | stop.fill | 暂停 + 指针回到 0 秒 |
| ▶ | 播放 | play.fill / pause.fill | 从指针位置播到尾 |
| ⟳ | **反选当前段** | 自定义（见下） | 指针所在段 绿↔红（留↔删） |
| ✂ | 切割 | scissors | 在指针处把这段劈成两半 |
| 💉 | 自动检测 | eyedropper（**吸管**） | 按当前阈值重算气口 |
| 右侧 | 当前时间码 | — | 跟随指针跳动 |

> **手机上分两行排，顺序不变。** 上面这一行一共 7 个 44pt 按钮 + 滑杆 + 时间码，
> 横着算下来要 480pt，而 iPhone 15 Pro Max 的可视宽度只有 398pt，一行塞不进去。
> 实际排法：
> - 第一行：`■ ▶ ⟳ ✂ 💉` ＋ 右侧时间码（高频操作，44pt 白圆）
> - 第二行：`↩ ↪` ＋ `− ────●──── +`（低频，± 是 28pt 小圆）


**⟳ 反选图标**（皓哥从 5 个方案里选的 B）—— 圆环双箭头首尾相接，自定义绘制：

```
M5 12a7 7 0 0 1 14 0
M19 12a7 7 0 0 1-14 0
M16 9l3 3 3-3
M8 15l-3-3-3 3
```
（viewBox 0 0 24 24，stroke 1.8，圆头圆角）

### 4.3 主轨道（关键几何）

**指针钉死在正中央不动，内容在底下左右滚。**

| 量 | 值 | 说明 |
|---|---|---|
| W | 可视宽度 | |
| pad | W/2 | 左右各留**半屏余量** |
| pps | 每秒像素数 | 由缩放决定 |
| L | duration × pps | 内容长度 |
| 画布总宽 | L + W | 内容 + 左右余量 |
| 滚动范围 | [0, L] | |
| **指针时间** | **= contentOffset / pps** | 因为 pad 恰好 = W/2，两者相消 |

> ⚠️ 余量必须取半屏，上面这条恒等式才成立。改任何一个数都要重推一遍。

- 滚动惯性和回弹交给 UIScrollView，不自己撸 pan
- 只有「拖边界把手」需要与滚动抢手势：摸到把手才临时关掉滚动
- 播放时内容持续向左滚（30fps 更新）

### 4.4 概览条

整条素材的缩略全览 + 橙色视窗框（标明你现在看的是哪一段）。点它任意位置直接跳过去。

补充：气口区间在概览条上也用粉红块画出（60% 透明）。定稿原文只写了「灰底小波形 + 橙色视窗框」，
但概览条上不标气口的话，就看不出「前面还有几刀没处理」，这条信息缺失会让概览条只剩导航价值。

### 4.5 底部两行

- 阈值滑杆：调灵敏度，松手 0.4 秒后重算
- 状态行：`原 00:42 · 剪后 00:38 · 7 刀 · 删 3.2s（7.6%）`

## 5. 手势

| 手势 | 发生什么 |
|---|---|
| 左右拖轨道 | 滚动，指针所指时间变，**画面同步跳帧** |
| 点轨道上某一段 | 该段 绿 ↔ 红 |
| 拖粉红块两端的小白条 | 微调这一刀边界 |
| 双指捏合 / 拖缩放滑杆 | 缩放 |
| 点概览条 | 跳到那个位置 |
| 左右滑画面 | 换上/下一条（多条素材时） |

## 6. 状态

| 状态 | 界面 |
|---|---|
| 正在提波形 | 轨道空着转圈，工具栏全灰 |
| 检测完成 | 粉红块铺开，状态行显示刀数 |
| 素材不适用（带 BGM） | 状态行黄字提示，吸管变灰 |
| 还没刀口 | 「还没有刀口 —— 调阈值或自己切」 |
| 导出中 | 按钮变灰 + 百分比 |
| 导出完成 | 「已存相册」，停在原地 |

## 7. 数据模型要点

- **切开 ≠ 删除**：`splits` 不进 `cutRanges`，导出时长不受影响
- 删除区间必须走 `BKTimeline.build`（内含 `merge`，会合并重叠）
- 拖动边界按**时间**找，不按 index（index 会随显示粒度变）

### 7.1 撤销 / 重做（2026-10-02 补）

- 撤销单位是**整个工程快照**（项目是值类型，一份才几百字节），
  不做「操作 + 逆操作」—— 两个气口重叠被 merge 之后逆不回原来的两条
- **一次拖动只占一格**：第一帧 `push`，之后全部 `amend`。
  反过来（先 amend）会把「拖动前的状态」覆盖掉，那一步就永远撤不回来了
- 上限 60 格。逻辑在 `tools/verify_history_stack.py` 里跑过 4000 组随机用例，
  改 `BKHistory.swift` 之前先跑一遍那个脚本
