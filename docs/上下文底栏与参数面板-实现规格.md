# 上下文底栏 + 自动蓝框 · 实现规格（v1.5.7）

> **来源**：`bk-clip-v15-ui` HTML 原型（2026-10-05 会话沉淀），原型已通过 8 套自动化验证。
> **本文是 UI 实现规格**，供 `app/UI/` 落地用。视觉/交互定稿见 `BK界面设计-竞品分析移交.md`。
> **交付顺序**：本文按「① 底栏骨架 → ② 各参数面板」分批，**先做 ①**。

---

## 0. 为什么要做这一层

原型的核心心智（务必先理解，否则会做歪）：

> **底部按钮永远作用于「当前框选的区块」。主轨区块被拖动经过中央指针时自动出蓝框，无需先点选。**

即：**底栏 = 当前上下文的函数**，而不是固定的全局工具栏。

### 术语对照（原型 → Swift）

| 原型 | 含义 | Swift 建议命名 |
|---|---|---|
| `selTrack` | 当前选中轨道 | `selectedTrack: TrackKind` |
| `selectedId` | 主轨选中区块 id | `selectedMainId` |
| `pipSelId` / `recSelId` | 侧轨选中 id | `selectedPipId` / `selectedRecId` |
| `barTrack` | 底栏当前显示哪套 | `barTrack` |
| 蓝框 `.tframe` | 主轨选中框 | 主轨 cell 的 `isSelected` |

## ① 第一批：底栏骨架（自动蓝框 + 上下文切换）

### 1.1 三套底栏（唯一真源）

| 轨道 | 按钮（左→右） | 数量 |
|---|---|---|
| **主轨（默认）** | 切割 · 波剪 · 音量 · 画面大小 · 旋转 · 左右镜像 · 变速 · 复制 · 删除 · 录音 | **10** |
| **录音轨选中** | 切割 · 音量 · 复制 · 录音 · 删除 | **5** |
| **画中画选中** | 切割 · 音量 · 替换 · 画面大小 · 旋转 · 左右镜像 · 变速 · 复制 · 删除 | **9** |

**规则**（伪码，直接照搬）：
```swift
func currentBarTrack() -> TrackKind {
    if selectedTrack == .pip, selectedPipId != nil { return .pip }
    if selectedTrack == .rec, selectedRecId != nil { return .rec }
    return .main                                  // 主轨恒为默认
}
```
> ⚠️ **默认必须是主轨**，不是"没选中就空"。这是「底栏永远有 10 键可用」的前提。

### 1.2 底栏尺寸与横滑

| 项 | 值 | 备注 |
|---|---|---|
| 底栏高 | **64pt** | `border-top: 1px` 分隔线 |
| 单键 | **42 × 48pt** | 圆角 **12pt** |
| 键间距 | **1pt** | 极窄，靠 42pt 宽度本身留白 |
| 横滑 | `overflow-x: auto` | **不换行、不压缩**（`flex: 0 0 auto`） |
| 滚动吸附 | `scroll-snap-align: center`<br>`scroll-snap-type: x proximity` | 每个键吸附到视口中心 |
| 视觉隐藏滚动条 | `::-webkit-scrollbar { height: 0 }` | 保留手势滑动 |

**实测数据（重要）**：10 键 × 42pt = **424pt**，屏宽 430pt，可视宽约 410pt
→ **溢出约 14pt，必须能横滑**。若强行压缩到不溢出，图标会挤到不可点。

> 现有 `docs/竞品布局实测.md` 记的是「7 图标等距 62pt / 距底 46pt」，那是**旧方案**。
> 本轮改为 **42×48pt 无文字纯图标 + 横滑**，请以后者为准。

### 1.3 图标规范
- **SF Symbols 单线条图标，不带文字**（悬浮菜单例外，按竞品用图标+文字）
- 删除键 `.del` 标红；其余 `color: var(--text-2)`
- `pressed` 态 `transform: scale(0.9)`
- 选中态 `.on` = `accent` + `rgba(47,109,244,.12)` 底

### 1.4 自动蓝框（核心逻辑）

**触发**：内容滚动时，判断中央指针落在哪个主轨区块内。

```swift
// 每次 applyScroll() 末尾调用
func autoFrameMain() {
    if selectedTrack == .pip || selectedTrack == .rec { return }   // 侧轨选中时让位
    let t = centerTime()                       // 指针处时间
    let hit = regions.first { t >= $0.a && t <= $0.b }             // 落在哪个区块
    let newId = hit?.id
    if newId == selectedMainId { return }      // ★ 未变则直接返回，不重绘
    selectedMainId = newId
    redrawMainTrack()                          // 只重绘选中框，不整表重建
    updateBarContext()
    updateMiniSelection(hit)
    updatePreviewTrack(.main)
}
```

**两个必须遵守的约束**（都是原型踩过的坑）：

1. **只在跨过区块边界时才重绘**
   `if newId == selectedMainId { return }` 这行是性能关键。
   原型早期每像素重绘，拖动明显卡顿。**不要因为"代码更简洁"去掉它。**

2. **程序化滚动必须让位**
   `selectBlock()` 会 `scrollTo` 让区块中心对准指针，这是**程序化滚动**。
   此时 `centerTime()` 落在的区块未必是目标区块（尤其滚动被边界夹紧时），
   自动蓝框会把刚选中的区块**覆盖回指针下的旧区块**。

   ```swift
   var autoFrameLock = false

   func scrollTo(_ t: TimeInterval, autoFrame: Bool = true) {
       autoFrameLock = !autoFrame        // selectBlock 传 autoFrame: false
       setOffset(t); applyScroll()
       autoFrameLock = false
   }

   func autoFrameMain() {
       if autoFrameLock { return }       // ★ 程序化滚动期间不覆盖选中
       ...
   }
   ```

   **症状**：复制片段后本该选中新段，结果选中态还停在原段。

### 1.5 点选与失焦
- **点区块** = 选中（蓝框 + 悬浮菜单 + 底栏切键组），同时**三轨同步滚动**使区块中心对准指针
- **点空白**（轨道空隙 / 迷你条 / 标签列 / 预览区 / 顶栏）= 取消选中，底栏回主轨 10 键
- 点悬浮菜单/底栏/工具面板**自身不取消**（`#bottombar`、`#toolPanel` 必须在"点空白关闭"的排除名单里）

> ⚠️ **这条极易漏**：若底栏没在排除名单里，用户按下音量键的瞬间选中态就被清空，
> 面板拿到空目标会**静默失败——不报错、无提示**，表现为"点了没反应"。

|---|---|

### 1.7 第一批验收点

## ② 第二批：参数面板

### 2.1 音量（连续滑块面板）

| 项 | 值 |
|---|---|
| 面板高 | 浮于底栏之上，底部留 **98pt** |
| 滑块 | 黄色 `#EAC54F` 填充 + **白色圆形把手**（直径 15pt） |
| 数值框 | 深底 + 圆角 8pt，`tabular-nums` 等宽数字 |
| 静音键 | 音量专属，值 = 0 时 `.on`（变 accent 色） |
| 底部键 | `✕` 取消 / `⌄` 展开「应用到全部」 / `✓` 确定（accent） |
| 「应用到全部」 | 居中**白色胶囊**，`#fff` 底 + `#12161c` 字 |

**数据**：`vol: Int(0...100)`。`vol == 0` ⇔ `muted == true`（主轨显示静音角标）。
「应用到全部」= 写全部区块；否则只写当前选中。

### 2.2 变速（线性，离散档位）

**已明确：只保留线性变速，无曲线变速**（v1.5.7 移除 Tab 栏）。

| 元素 | 规格 |
|---|---|
| 档位 | `0.1x · 0.5x · 1x · 1.5x · 2x · 3x · 4x` 共 **7 档** |
| 选中态 | 黄底 `#EAC54F` + 深色字 `#151A20` + semibold |
| 刻度尺 | **41 根**（每 5 根加长为 `maj`），游标 `#EAC54F` 高 17pt，可拖 |
| 时长 | 左上「时长 x.xxs」，**随档位实时联动** |
| 底部键 | `✕` / `✓✓` 应用到全部 / `✓` 确定 |

**① 对数映射**（关键，别用线性）
```swift
let LO = log(0.1), HI = log(4)
func spdToPct(_ v: Double) -> Double { (log(clamp(v,0.1...4)) - LO) / (HI - LO) }
func pctToSpd(_ p: Double) -> Double { exp(LO + (HI - LO) * p) }
```
> 线性铺的话 0.1~1x 会占掉 87% 刻度，2x~4x 全挤在一起没法拖。

**② 档位吸附有阈值**
```swift
func snap(_ v: Double) -> Double {
    // 差值 < 0.06 才吸附到档位，否则保留连续值
}
// 效果：点档位 = 精确 2x；拖刻度尺可得 1.3x（此时无档位高亮）
```

**③ 变速真实改变轨道结构**（不是只打标记）
```
时长 = 原始时长 / 倍速
片段 b = a + 原始时长 / 倍速
主轨片段连续 → 后续所有片段按 delta 平移
TOTAL 同步增减，刻度尺重建
相邻片段仍首尾相接（seg0.b == seg1.a）
```

**④ 必须锁存原始时长**（幂等）
```swift
// ✅ 正确：首次记录 speed=1 时的时长，之后恒用它做基数
if item.baseDuration == nil { item.baseDuration = item.duration }
let newLen = item.baseDuration! / speed

// ❌ 错误：拿当前 duration 当基数 → 二次打开面板会重复累乘
//    实测：7s → 2x 得 3.5s → 再开面板变 1.75s（应为稳定的 3.5s）
```

**⑤ 改 TOTAL 后要重锁选中态**
变速会改 `TOTAL` → 触发 `applyScroll` → `autoFrameMain` 重新框选指针下区块，
**用户刚编辑完的区块会失选**，下次开面板回显错档位。
```swift
// applySpeed 内：
autoFrameLock = true
redrawAll()
setSelected(track, keepId)          // 显式复位到刚编辑的区块
scrollTo(center(keepId), autoFrame: false)
autoFrameLock = false
```

**⑥ 录音轨不支持变速**（无画面），底栏也不出该键。

### 2.3 画面大小 / 旋转 / 左右镜像（主轨 + 画中画通用）

这三个**主轨和画中画共用同一套实现**，不要写两遍。

```swift
func visualTarget(_ track: TrackKind) -> Item? {
    // main → regions 里 selectedMainId 那个
    // pip  → pipItems 里 selectedPipId 那个
    // rec  → nil（无画面）
}
```

| 功能 | 交互 | 数据 |
|---|---|---|
| 画面大小 | 滑块 **50% ~ 200%**，步长 1 | `scale: Int`（默认 100） |
| 旋转 | 每次点击 **+90°**，循环 0/90/180/270 | `rot: Int`（默认 0） |
| 左右镜像 | 每次点击**取反** | `flip: Bool`（默认 false） |

- 结果**实时反映在预览画面**上：`.canvas .frame-img` 应用 `scale() rotate() scaleX(-1)`
- 预览右上角角标显示 `90° · 镜像 · 120%`（三段用 `·` 分隔）
- 角标 id 沿用 `#pipBadge`，**主轨也复用它**（不只是画中画）
- 三个参数**逐片段存储**（挂在各自区块上），复制片段时随深拷贝一起带走
- 「应用到全部」= 写当前轨道的全部区块

### 2.4 画中画「替换」

复用主轨已有的替换流程，只需把目标轨参数化：
```
startReplace(track)   // main: 锁定时长替换；pip: 同流程，替换 src
```
流程：记录目标 → 素材库 → 预览 → 片段选择 → 回填。
`replaceTrack: TrackKind` 标记本次替换作用哪条轨。

## ③ 数据模型改动

```swift
// 主轨片段新增
struct Region {
    // …原有字段…
    var vol: Int = 100
    var speed: Double = 1
    var baseDuration: Double?      // ★ speed=1 时的原始时长（变速幂等用）
    var scale: Int = 100
    var rot: Int = 0
    var flip: Bool = false
}
// 画中画新增：vol / speed / scale / rot / flip（同上）
// 录音新增：vol（不支持画面参数与变速）
```
> 字段名沿用原型的 `bBase` 语义（"base duration"），Swift 侧建议叫 `baseDuration` 更清晰。
