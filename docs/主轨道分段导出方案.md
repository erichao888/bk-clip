# 主轨道分段导出 · 方案定稿（v2.0）

> 2026-10-05 整理。非破坏式「选区导出」功能：在主轨选一段 → 导出成单独成品，草稿本身不动。
> 这是剪映**手机版**缺失的能力（要导出一部分只能拖短草稿或复制草稿再删），是 bk剪辑的差异化卖点。
> 本文件是此功能的**唯一真源**；实现前先看这份，改交互/映射先改这份再改码。

---

## 0. 定位与差异化

- **非破坏式选区导出**：选区是导出前的临时状态，关掉/重进草稿即清；草稿数据完全不动。
- 剪映**手机版**没有「select range → export range」：要导出一部分只能 (1) 拖短草稿两端 (2) 复制草稿再删。
  （剪映 PC/专业版有「部分导出」，但手机端没有——正是我们要占的空位。）
- 导出产物 = 已跳过气口的干净片段（与全量导出语义一致）。

---

## 1. 交互设计（怎么选）

两种入口都可进「选区间模式」（皓哥 2026-10-05 拍板：两者都要）：

1. **底部工具栏「选区间」线条图标按钮**（图标皓哥设计，沿用线条风）：点一下进模式。
2. **主轨长按**：长按主轨空白处也进选区间模式（长按在别处语义不冲突，可用）。

进入模式后：
- 主轨上方出现**蓝色半透明选区带 + 两个蓝色入/出点把手**（复用现有 region-edit 把手手势，
  但用品牌蓝 `#2F6DF4` 区分于编辑黄框，避免混淆）。
- 拖两把手设定区间；**点某个片段 → 选区 snap 到该片段整段**（快速整段导出）。
- 选区有效时底部出现「**导出选中**」确认按钮；无选区 / 零宽则禁用。
- 退出：再点按钮或点空白。

| 操作 | 结果 |
|---|---|
| 点「选区间」按钮 / 主轨长按 | 进模式，主轨出现蓝色选区带 |
| 拖入点 / 出点把手 | 设定导出区间 |
| 点某片段 | 选区 = 该片段整段（快速整段导出） |
| 点「导出选中」 | 导出该区间为单独 MP4 |
| 点空白 / 再点按钮 | 退出模式，清选区 |

⚠️ **手势仲裁**：选区间模式内把手拖动优先；进模式后**屏蔽双击进波剪**避免误触；点空白退出。

## 2. 坐标映射（核心：怎么导出「对的段」）

主轨输出时间轴 = 各片段 `outputDuration` **首尾相接**（prefix sum）。
选中全局区间 `[G0, G1]` → 逐片段求交得局部输出子区间 → 经该片段 **`foldMap`（输出→源）**
得原片区间（**仅绿区，气口已排除**）→ 收集 `(素材, 原片区间)`。

| 主轨全局输出 | → 片段 i | → 片段内局部输出 | → 原片区间（绿区） |
|---|---|---|---|
| `[G0, G1]` | 求交得 `[lo, hi]` | `[lo − Gi0, hi − Gi0]` | `foldMap` 映射，气口自动跳过 |

- `foldMap` 是 `BKTimeline.foldMap`：`[(out, src, dur)]`，输出→源对照，只含绿区。
- 每段映射：`localOut` 子区间 `[lo−Gi0, hi−Gi0]` 与每个 foldMap 段 `[out, out+dur]` 求交，
  交得 `[s, e]` → 原片 `[src + (s − out), src + (e − out)]`，收集为该片段的原片区间列表。
- 跨片段收集所有 `(asset, 原片区间[])` → 交给新 builder 顺序拼成一条 composition。

**关键点**：`foldMap` 只映射绿区 → 选区内气口天然被跳过，与全量导出语义一致。

⚠️ **整段映射是纯逻辑**，先 Python 复刻验证不变量（边界对齐 / 无气口泄漏 / 跨片段连续）再写 Swift。

## 3. 复用 vs 新增（代码量很小）

| 复用（已有，勿重写） | 新增 |
|---|---|
| `BKCompositionBuilder.make(asset:keeps:)` 的 `insertTimeRange` 音视频成对拼逻辑 | 主轨拼接 prefix-sum（纯逻辑） |
| `BKExporter` drain 三趟 + 长度校验 + 2 次重试报错 | `selection → segments` 映射（纯逻辑，Python 验证） |
| 每片段 `BKTimeline.foldMap` / `BKProject.outputDuration` | 主轨蓝色选区带 + 把手 UI + 手势仲裁 |
| region-edit 把手手势 / `BKVideoLibrary.loadAVAsset(localID:)` | `BKCompositionBuilder.make(segments:)` 重载 |
| `BKRootViewController.saveToPhotos(url:fileName:)` | `BKExporter` 接收 segments 的入口 |

新增 builder 签名（与现有 `make(asset:keeps:)` 并列）：
```swift
static func make(segments: [(asset: AVAsset, keeps: [(Double, Double)])]) -> BKCompositionBuild?
```
内部逻辑 = 把现有 `make` 的「单 asset 内遍历 keeps」改成「遍历 segments，每个 segment 内遍历其 keeps」，
音视频成对插入的规则完全不变（复用现有 insert 配对 + 时长夹取）。

## 4. 全量导出一并改为「拼成一条」（皓哥 2026-10-05 拍板）

当前 `BKEditorViewController.exportLoop` 是**每段单独导出一个文件**；v2.0 主轨定位是「一条时间轴 = 一个成品」。

- 新增的 `make(segments:)` **同时服务两者**：
  - **全量** = 所有片段的全部绿区（`items.map { ($0.asset, $0.keepRanges) }`）。
  - **分段** = 选中片段的选中绿区子区间（见 §2）。
- 两者同一管线、行为一致：主轨导出 = 一个成品视频。
- ⚠️ 这是把全量导出从「逐条分别导出」改成「拼成一条」，**属行为变更**，但符合 v2.0 设计，已确认。

---

## 5. 叠加轨（录音 / 画中画）裁剪进选区（皓哥 2026-10-05 拍板：一起裁剪）

分段导出**不只主轨**，录音轨 / 画中画轨也按选区时间裁剪后并进成品。

- 叠加轨在主轨输出时间轴上的位置为 `[ovStart, ovEnd]`（output time）。
- 选中 `[G0, G1]` → 相交得 `[ovLo, ovHi]`（选区内可见段）。
- 该段在**导出成品**内占 `[ovLo − G0, ovHi − G0]`。
- 叠加内容裁剪：
  - **录音** = 音频轨：取其源内容对应子区间，按 `[ovLo − G0, ...]` 放进导出 composition 的音频轨。
  - **画中画** = 视频轨（静帧或视频）：取其源内容子区间，通过现有叠加合成路径
    （`AVVideoComposition` 指令 / `audioMix`）按 `[ovLo − G0, ...]` 合成进导出视频。
- **复用全量导出的叠加合成路径**：分段导出只是把「全量时间范围」换成「选区时间范围」传进去，
  叠加的合成/淡入淡出逻辑不变。
- 实现依赖：全量导出的叠加合成路径先存在（v2.0 导出管线的一部分）。分段导出与它同源，只换时间范围。

## 6. 产物与落点

- 一个 MP4 存相册（同现有 `saveToPhotos`），文件名 `BK_选中_<时长>.mp4`（复用 `nextExportFileName` 命名规则）。
- 可选 bonus（后续）：**「导出为草稿片段」**——把选区作为新片段插回主轨（二次创作）。

---

## 7. 边界与坑

- **跨片段选区**：§2 通用逻辑已覆盖（多素材顺序拼）。
- **选区落在气口**：主轨输出轴无气口，不可能发生，无需处理。
- **选区切到某片段内部气口**：`foldMap` 给两侧绿区两段原片区间，气口跳过（预期行为）。
- **零宽 / 未选**：禁用「导出选中」。
- **叠加轨裁剪**：依赖 §5 的叠加合成路径；选区让某叠加轨只剩部分 → 按 §5 裁剪，空出的主轨区域不补。
- **长度校验仍生效**：子 composition 也走现有「长度差 ≤ 1 帧 + 余量，两次不一致报错停止」。
- **手势仲裁**：选区间模式内把手拖动优先；进模式后屏蔽双击进波剪；点空白退出。

## 8. 实施分批（先定稿，再写码）

1. **P1 纯逻辑（Python 验证）**：主轨拼接 prefix-sum + `selection → segments` 映射。
   不变量：选区边界对齐、无气口泄漏、跨片段连续、选区=整轨时等价于全量。
2. **P2 导出基建**：`BKCompositionBuilder.make(segments:)` + `BKExporter` 接收 segments 的入口；
   全量导出改用 `make(segments:)`（§4 行为变更）；叠加轨裁剪（§5）。
3. **P3 交互**：主轨蓝色选区带 + 入/出点把手 + 「选区间」按钮 + 主轨长按入口 + 手势仲裁 + 「导出选中」按钮。
