## ② 手势优先级与状态机

### 2.1 手势冲突矩阵（★ 顺序错就会出 bug）

单指落在不同区域，**命中谁就归谁**，互不争抢：

| 命中目标 | 归属 | 说明 |
|---|---|---|
| 轨道区**空白** | 拖动 = 滚动 | 阈值 `|dx| > 3pt` 才算拖动，否则算点击 |
| 区块本体（主轨/画中画/录音） | 点选 = 选中 | 拖动**不在本轮范围**（见 §4 待确认） |
| 三轨**横向滚动** | 锁定同步 | 录音/画中画/主轨**共用同一 trackT 轴**，一次 pan 三轨同移；左列标签固定不随内容滚 |
| 悬浮菜单 / 底栏 / 工具面板 | 自身消费 | **不冒泡到"点空白"**，见 2.3 |
| 迷你概览条 | 拖蓝框 = 移动视窗 | 独立逻辑 |
| 变速刻度尺 | 拖动 = 调速 | `pointerdown` 立即响应 + 指针捕获 |

> **★ 关键**：`pointerdown` 必须 `setPointerCapture` + `preventDefault`，
> 否则 iOS 上滑动手势会抢走拖动（原型 `spdScale` 已这么做）。

### 2.2 状态机（编辑页选中态）

```
                    点空白 / 点菜单外
        ┌──────────────────────────────────┐
        ↓                                  │
   ┌─────────┐   点画中画块    ┌────────┐  │
   │  MAIN   │ ──────────────→ │  PIP   │  │
   │ 默认10键 │                 │ 9键    │  │
   └─────────┘ ←────────────── └────────┘  │
        │                                  │
        │ 点录音块          点画中画块      │
        ↓                                  │
   ┌─────────┐                            │
   │   REC   │ ───────────────────────────┘
   │  5键    │
   └─────────┘
```

**规则**：
- 无任何选中 → `currentBarTrack() == .main`（**不是空态**，恒有 10 键）
- `selTrack` 与 `selectedId` **必须成对**存在；单侧有值视为脏态，需复位
- 切轨时侧轨选中态**保留**（再次点同一块可回到底栏对应键组）

### 2.3 「点空白关菜单」的排除名单（★ 最易漏）

```
白名单（点这些**不**取消选中）：
  #floatbar, #recPop, #recLive,
  .thit, .pblk, .rblk, .tadd,          ← 区块本体
  .mini, #tlLabels, #tlScroll,         ← 轨道区
  #bottombar, #toolPanel, #spdPanel    ← ★ 底栏与面板必须在内
```

> **症状**：漏了 `#bottombar` → 用户按下音量键的瞬间选中态被清空 →
> 面板拿到空目标**静默失败，不报错、无提示**，表现为"点了没反应"。
> 这是本轮实际踩过的坑，务必核对。

### 2.4 录音浮层（已有，勿回归）

- `toggleRecPop` 幂等切换 `.show`
- 录音态（`recState != idle`）点按键 = **强制显示**浮层，不做切换
- 录音中轨道自动跟随滚动 + 实时波形
- 浮层位置按底栏「录音」键动态计算（`placeRecPop`），贴屏幕边缘时收敛

## ③ 坐标换算与吸附规则（含边界）

### 3.1 换算链（原型实测常量）

```
PPS = 26                     像素/秒（主轨时间轴密度）★ 双指缩放时为动态值（let），默认 26
PPS_MIN = 8, PPS_MAX = 80    缩放范围（纯视图层，不进数据模型）
X(t) = t * PPS               秒 → 内容像素（PPS 变化即整体重绘）
viewW()    = 视口宽（iPhone 15 Pro Max 实测 358pt，屏 430 - 左右各 36）
contentW() = TOTAL * PPS     内容总宽（随 PPS 缩放）
HALF       = viewW()/2 = 179pt   半屏空腔（起点/终点到指针）
scrollMin  = −HALF = −179pt
scrollMax  = contentW() − HALF   ★ 随 PPS 缩放：max(−HALF, TOTAL*PPS − HALF)

指针处时间：
centerT() = (scrollOffset + viewW()/2) / PPS
屏内任意 x 处 trackT：
trackTAt(x) = (scrollOffset + x) / PPS      ★ 双指缩放焦点稳定用
```

> 原型 `viewW()` 兜底 358，`contentW()` 随 `TOTAL` 动态变化；`PPS` 改为 `let` 后随双指缩放变化（§3.2.2）。
> ⚠️ **PPS 是纯视图变换**：trackT 永远以秒计，**缩放不进数据模型、不影响折叠/变速/导出**。
> **实测**：30s 素材 → contentW = 780pt，scroll ∈ [−179, 601]（可滚动）。
> ⚠️ **2026-10-05 皓哥拍板（竞品式）**：静止边界从旧版 `[0, contentW−viewW]` 改为
> **`[−HALF, contentW−HALF]`**——时间线**起点/终点静止时与中央指针对齐**（两端各留半屏空腔，
> 只留白、不进数据模型），并新增**过拖橡皮筋 + 松手回弹**（§3.2.1）。

### 3.2 固定中央指针 + 内容滚动（模型）

- 指针 `.tl-play` **固定在 `left: 50%`，不动**
- 滚动的是内容（`translateX(-scrollOffset)`）
- 三轨（主/画中画/录音）**共用同一 scrollOffset** → 垂直严格对齐
- `scrollOffset` **静止边界必须夹取** `[−HALF, contentW() − HALF]`；手指拖动中允许越界（§3.2.1 橡皮筋）

**两端可达性（不变量）**：
```
scrollOffset = −HALF           → t=0 落在屏幕正中（指针压住轨道起点）
scrollOffset = contentW − HALF → t=TOTAL 落在屏幕正中（指针压住轨道终点）
```

### 3.2.1 过拖橡皮筋 + 松手回弹（★ 2026-10-05 皓哥拍板，竞品式）

| 项 | 规则 |
|---|---|
| 手指拖动越界 | 允许；显示位移 = `OVER × tanh(原始越界量 / OVER)`，越拖越紧 |
| OVER（最大可视过拖） | `0.3 × viewW()` ≈ 107pt |
| 松手回弹 | 越界则 ~250ms ease-out spring 回弹到最近静止边界（起点侧弹回 `−HALF`，即轨道起点与指针对齐） |
| 程序化滚动 | `scrollToT` / 录音跟随 / 迷你条拖动**不走橡皮筋**，直接夹取到静止边界 |
| 作用范围 | 三轨 + 刻度尺 + 迷你条视窗框同步（同一 scrollOffset） |
| 数据模型 | 空腔与过拖**纯视图层**，不进模型、不影响导出（§3.3 余量区同规则） |

> 竞品参照：剪映类时间线两端均为「起点/终点可拖到指针下 + 过拖回弹」。
> 我方原型旧版为硬夹取 `[0, maxScroll]`（起点贴左缘、无回弹），已按本节废弃。

### 3.2.2 双指缩放（★ 2026-10-05 皓哥拍板，竞品式）

| 项 | 规则 |
|---|---|
| PPS 动态 | 原 `const PPS=26` → `let PPS`，默认 26；缩放范围 `PPS_MIN=8`，`PPS_MAX=80`（px/s） |
| 缩放范围含义 | PPS=8：30s ≈ 240px ≤ 视口，整条时间线可见、滚动边界收窄；PPS=80：30s ≈ 2400px，单屏约 4.5s，看波形/缩略图细节 |
| 视图层 | 只改 PPS + 整体重绘，**不进数据模型**（trackT 永远以秒计，不影响折叠/变速/导出） |
| **焦点稳定** | 缩放保持焦点处 trackT 不变：`focusT = (scrollOffset + focusX) / PPS`（focusX = 双指中点 / 光标 的屏内 x）；改 PPS 后 `scrollOffset = clampScroll(focusT * PPS − focusX)` |
| 夹取边界 | 缩放后若理想焦点越界（内容滚到头），`scrollOffset` 夹到最近静止边界，**焦点漂移属不可避免**（物理上手指处内容点滑走） |
| 重绘范围 | `buildRuler()` + `renderWave()` + `renderThumbs()` + `renderSideTrack('pip'/'rec')` + `applyScroll()`（设 body 宽 + translate + mini 同步） |
| 桌面回退 | `Ctrl + 滚轮`（Mac 触控板双指捏合也发此事件）触发缩放，`preventDefault` 阻止浏览器整页缩放；焦点取光标屏内 x |
| 与拖动互斥 | 缩放中禁用单指拖动（`isPinching` 标志），任一根手指抬起后恢复 |

> 不变量（`tools/verify_bottombar.py` 新增断言 **B5** 覆盖，5000/5000 绿）：
> 任意 PPS ∈ [8,80]，静止边界 = `[−HALF, max(−HALF, TOTAL*PPS − HALF)]`；
> **未夹取时**焦点 trackT 误差 < 1e-6；**已夹取时**新 offset 严格等于边界。

### 3.3 命中测试与边界

| 场景 | 规则 |
|---|---|
| 点前半屏余量 | 视为 `t=0` |
| 点后半屏余量 | 视为 `t=TOTAL` |
| **不允许** | 负时间 / 超界时间 |
| 吸附锚点 | `0` 与 `TOTAL` 均为合法锚点 |
| 自动蓝框命中 | `t ∈ [区块.a, 区块.b]`（**闭区间**） |

> 余量区**只留白**：不画波形、不画刻度、不画 clip，且**不进数据模型、不影响导出**（纯视图层）。

### 3.4 自动蓝框的滚动夹取（★ 边界坑）

```swift
func scrollTo(_ t: TimeInterval, autoFrame: Bool = true) {
    autoFrameLock = !autoFrame
    setOffset(clamp(t * PPS - viewW()/2, -viewW()/2, maxScrollPx()))   // ★ 必须夹取（下界 −HALF：起点可到指针下）
    applyScroll()
    autoFrameLock = false
}
```

**症状**：不夹取时，靠近轨道末尾的区块无法居中，`centerT()` 落在别的区块上，
自动蓝框把选中态覆盖回旧区块。**边界处（已到 −HALF 或 scrollMax）必测。**

### 3.5 变速刻度的对数映射（★ 非线性）

```swift
let LO = log(0.1), HI = log(4)
spdToPct(v) = (log(clamp(v, 0.1...4)) - LO) / (HI - LO) * 100
pctToSpd(p) = exp(LO + (HI - LO) * p/100)

snap(v): 吸附到最近档位，当 |档位 - v| < 0.06；否则保留连续值
```
> 线性铺会导致 0.1~1x 占 87% 刻度、2x~4x 挤成一团。**必须用对数。**

### 3.6 片段时长改写（变速）

```
时长 = baseDuration / speed            baseDuration 锁存于 speed=1 时的值
newB  = a + baseDuration / speed
delta = newB - oldB
后续所有片段（a >= oldB）: a += delta; b += delta
TOTAL = Σ (b - a)
```
**边界**：`speed ∈ [0.1, 4]`；`delta == 0` 时**跳过平移**（避免浮点误差累积）。

### 3.7 区块左端装饰（★ 2026-10-05 皓哥拍板，竞品式）

| 轨道 | 左端装饰 | 实现 |
|---|---|---|
| 画中画轨 | **小缩略图 + 时长** | `.pblk` 左端 `.pthumb`（固定 ~34×100% 圆角左，渐变底 + 播放三角），其上/下方 `.bdur` 显示本段时长 `(b-a).toFixed(2)+'s'`；源名 `.lb` 右移到 `.pthumb` 之后（`left:40pt`） |
| 录音轨 | **时长** | `.rblk` 左端 `.bdur` 显示本段时长；无缩略图（录音非画面） |
| 主轨 | （沿用既有蓝框 `.tframe .dur`） | 选中才显时长，常态不显（保持主轨纯净） |

- `.bdur`：绝对定位 `left:4pt; bottom:3pt`，半透明黑底白字 `9pt`，`pointer-events:none`，压在缩略图/波形上不挡点选。
- 选区蓝框 `.psel/.rsel/.tframe` 的 `.dur` 仍置 `top:2pt`，与 `.bdur` 上下错开不重叠。
- 极短区块（宽 < 34pt）：缩略图 `max-width:100%` 被裁切，源名/时长一并裁切，**属预期**（皓哥 2026-10-05 确认：缩小后文字被挡就让它挡着，不做分档隐藏）。
- 缩略图内容为**占位**（原型无真帧），Swift 落地时用 `AVAssetImageGenerator` 取每段首帧；时长由 `b-a` 现算（含变速后 `timelineDuration`）。

## ④ 各页面状态清单

### 4.1 编辑页

| 状态 | 表现 |
|---|---|
| 空（无素材） | 轨道空、底栏仍 10 键（禁用态灰） |
| 加载中 | 缩略图占位灰块 |
| 正常 | — |
| 点空白 | 取消选中，底栏回主轨 10 键 |
| 底栏横滑 | 可滑到两端，首尾键完整可见可点 |
| 录音浮层开 | 遮住时间轴底部（**测试拖轨道前需先收起**） |
| 面板打开 | 底栏上方浮出面板，**底栏仍可点**（换面板用） |

### 4.2 面板（音量/变速/画面）

| 状态 | 表现 |
|---|---|
| 打开 | 浮出，底栏保持可见 |
| 拖动中 | 数值/游标实时更新（**不落库**） |
| 取消 `✕` | 关闭，**不写回** |
| 确定 `✓` | 关闭并写回 |
| 应用到全部 `✓✓` | 写全部区块（当前轨道） |
| 无选中 | 不应被唤起（若发生=白名单失效，见 2.3） |

### 4.3 空/加载/错误三态（通用要求）

| 状态 | 要求 |
|---|---|
| 空态 | 有引导文案 + 可点击的下一步动作，**不留白屏** |
| 加载态 | 骨架/占位，**布局不跳**（预留最终尺寸） |
| 错误态 | 说明原因 + 可重试入口，**不弹裸 toast 了事** |

> 每个可点元素都要有真实功能，不能只弹 toast ——「点了没反应」和「功能坏了」用户分不出来。
