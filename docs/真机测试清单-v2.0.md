# v2.0 真机测试清单（每版固定跑这套，版本间才有可比性）

> 2026-10-05 立。配套 `docs/开发期真机测试.md`（旧版）+ `docs/v2.0数据模型-多片段主轨与变速坐标.md`。
>
> **为什么要有固定清单**：版本之间只跑同一套动作，才能回答「这版好了还是坏了」。
> 各跑各的 → 出了问题说不清是哪一步引入的，等于白测一轮。
>
> **一轮的成本**：云编译 ≈ 6~10 分钟 + 爱思签名安装 ≈ 2 分钟。
> 所以每一轮都要榨出最多信息 —— 出问题**先取日志再继续**，别急着重试。

## 报障模板（出问题直接照填发我）

```
版本/提交: v2.0.0-bx (日志头 commit xxxxxx)
机型/iOS:  iPhone 15 Pro Max / 26.6.2   （或 16 Pro / 26.2）
现象:      崩溃 / 卡住 / 结果不对 / 没反应
必现?:     必现 / 偶现（几次）
步骤:      1… 2… 3…（照下面清单的编号写，如「第 7 步」）
附件:      日志导出文本 + 草稿快照
```

## A. 启动与日志（每版第一件事）

| # | 动作 | 预期 |
|---|---|---|
| A1 | 冷启动 App | 日志头出现 `会话开始 v… commit xxxxx · iPhone… · iOS …` |
| A2 | 看 commit 是不是本版提交 | **不是 unknown**（unknown 说明 CI 没注入 SHA） |
| A3 | 进后台再回前台 | 无异常退出告警 |
| A4 | 强制杀进程再启动 | 下次启动报「上次异常退出」（这是**预期**，说明捕获链路是通的） |

> A4 报出来才是好事 —— 说明崩溃检测活着。

## B. 相册与导入

| # | 动作 | 预期 |
|---|---|---|
| B1 | 首次点「选视频」 | 弹相册权限；**16 Pro（iOS 26.2）上必须弹**（这是已知的兼容性风险点） |
| B2 | 一次导入 ≥ 3 个片段 | 主轨出现 3 块，首尾相接无缝 |
| B3 | 其中一段进波剪页再返回 | 该块视觉变短（折叠形态），其余块不动 |

## C. 轨道交互（本轮重点）

| # | 动作 | 预期 |
|---|---|---|
| C1 | 单指横向拖动 | 三轨**同移**，左列标签不动 |
| C2 | 拖到最左端 | 起点弹到与**中央指针**对齐（过拖有橡皮筋、松手回弹） |
| C3 | 拖到最右端 | 同上，对称 |
| C4 | 双指捏合缩放（或 Ctrl+滚轮） | 缩略图/波形随缩放重绘；画中画块左端有缩略图+时长，录音块左端有时长 |
| C5 | 缩到最小 | 整条时间线可见；文字被挡属**预期**（你确认过不改） |
| C6 | 点选某块 | 自动蓝框 + 底栏切到对应键组 |

## D. 编辑操作（对应 I1–I12）

| # | 动作 | 预期 |
|---|---|---|
| D1 | 在某块中间切割 | 切成两块，总长不变，接缝无缝 |
| D2 | 插入新片段 | 后续块顺移，总长增加 |
| D3 | 替换（选更长的素材） | 时长锁定不变，块变单段 |
| D4 | 替换（选**更短**的素材） | 拒绝并提示「素材太短」，原块不变 |
| D5 | 改某块变速 | 该块变短/变长；**录音轨的 clip 跟着平移** |
| D6 | 拖动重排某块 | 顺序改变，接缝仍无缝 |
| D7 | 进波剪页改绿区再返回 | 该块时长变化；其后的录音 clip 跟着平移（联动） |

## E. 叠加轨

| # | 动作 | 预期 |
|---|---|---|
| E1 | 录一段音 | 落在指针处的输出时间；波形出现 |
| E2 | 移动/改主轨后看录音位置 | 跟着画面走（联动） |
| E3 | 加画中画并拖动定位 | 预览与导出一致 |

## F. 导出（最容易出问题，放最后）

| # | 动作 | 预期 |
|---|---|---|
| F1 | 导出单段 | 存进相册；能进剪映 |
| F2 | 导出多片段（含变速 + 录音） | 音画同步；总长 = Σ 各块时长 |
| F3 | 导出中切后台 | 不崩；回来能完成或明确报错 |
| F4 | 故意造一个失败（如磁盘满） | **明确报错，不无限重试、不崩** |

## G. 取日志（出问题时的动作）

调试面板入口：**起始页连点版本号 7 次**。

1. 「导出日志」→ 分享到微信文件传输助手 / 邮件（Windows 没 AirDrop）
2. 顺手把**草稿快照**一起发我 —— 有了它我能在 Python 里复现你的时间线
3. 若提示「上次异常退出」→ crashes 目录里的报告一并给我
