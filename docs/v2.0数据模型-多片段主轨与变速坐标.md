## 1. 区块统一结构（★ 本批最关键的收敛）

主轨上的每一个片段，无论有没有做过波剪，都是**同一份结构**：

```swift
struct BKClipBlock: Codable, Identifiable {
    var id: UUID
    var assetLocalID: String      // 相册素材
    var srcDuration: Double       // ① 源素材总时长（永远不变）

    var keptRanges: [BKRange]     // 源时间上的保留区间（绿区），升序、不重叠
    var speed: Double = 1.0       // 逐区块倍速（★ 每块独立）

    // 派生（不存储）：
    var baseDuration: Double { keptRanges.reduce(0) { $0 + $1.length } }  // ② speed=1 时折叠后时长
    var timelineDuration: Double { baseDuration / speed }                 // ③ 主轨/输出上占的时长
}
```

### 1.1 两种形态只是同一结构的两种取值（零分支）

| 形态 | `keptRanges` | `baseDuration` |
|---|---|---|
| **未波剪**（直接添加） | `[(0, srcDuration)]` —— 单段，整段保留 | `= srcDuration` |
| **已波剪**（进过波剪页） | 多段绿区（红区被折叠掉） | `< srcDuration` |

> ✅ **这条收敛直接消除了「两种情况分别对待会出错」的风险**：
> 所有编辑操作只认 `keptRanges` 列表，代码路径只有一条，**没有 `if 有没有波剪` 分支**。
> 未波剪只是「列表长度为 1」的退化情况。

### 1.2 字段为什么这样拆（决策 ②）

`srcDuration`（源素材物理长度）与 `timelineDuration`（在本轨上占的时长）**必须分开**：
- 前者永不改变，是裁剪/折叠的合法边界；
- 后者随「折叠程度」和「speed」实时变，是布局与导出的依据。

`baseDuration` 是 speed=1 时的折叠后时长，`timelineDuration = baseDuration / speed`。

## 2. 三套坐标

| 轴 | 范围 | 说明 |
|---|---|---|
| **源时间 `src`** | `0 ~ srcDuration` | 永不改变。所有 `keptRanges` 的存储坐标系 |
| **片段内折叠后 `folded`** | `0 ~ baseDuration` | 去掉红区后的该片段时间 |
| **轨道/输出 `trackT`** | `0 ~ TOTAL` | 多片段首尾相接；**★ `out == trackT`（决策 ⑤，两轴合一）** |

> ⚠️ `v2.0技术方案` §1 曾把 out 与 trackT 当两套轴。决策 ⑤ 已合并：
> **speed 同时压缩两者**，不存在独立的 out 换算。

### 2.1 两级坐标映射（地基）

**第一级 · 片段内（折叠）**：`folded → src`

```
累计绿区长度定位到某段 j：
    cum = Σ_{k<j} (b_k − a_k)
    src = a_j + (folded − cum)
```

**第二级 · 主轨（拼接 + 变速）**：`trackT → folded → src`

```
T_i        = Σ_{k<i} timelineDuration_k          （前缀和，块 i 在主轨上的起点）
local      = trackT − T_i                        （在本块内，0 ~ timelineDuration）
folded     = local × speed_i                     （★ 先解变速，回到折叠空间）
src        = foldMap_i(folded)                   （再解折叠，回到源空间）
out        = T_i + local                         （★ out == trackT）
```

**反向**（`src → trackT`）：`src` 落在 `keptRanges[j]` 内 →
`folded = 前缀绿区长 + (src − a_j)` → `local = folded / speed_i` → `trackT = T_i + local`。

### 2.2 唯一顺序：**先折叠，再变速**（决策 ④）

```
源素材 --(定绿区/折叠)--> baseDuration --(除以 speed)--> timelineDuration
```

- 折叠**先**定死绿区（`keptRanges`），变速只把结果整体压缩，**不改绿区本身**。
- 反过来的话，变速后的时长再去折叠会引入「折叠量要不要跟着缩放」的歧义，禁止。

### 2.3 逐区块倍速（决策 ③，★ 禁全局乘数）

每块有自己的 `speed_i`，**不能用统一乘数**。混合倍速天然支持；
「应用到全部」= 把所有块的 `speed` 拉平成同一个值。

## 3. 主轨多片段拼接

```
T_0 = 0
T_i = Σ_{k<i} timelineDuration_k
TOTAL = Σ_k timelineDuration_k
```

- 主轨显示宽度 = `TOTAL × PPS`（PPS 随双指缩放变化，**纯视图**）。
- 录音轨 / 画中画轨**共用同一条 trackT 轴**、同一 `scrollOffset`（三轨同步滚动）。

## 4. 编辑操作的落点与规则

所有操作**都必须走上面的映射**，不允许绕过 `foldMap` 直接写源时间。

| 操作 | 落点 | 规则 |
|---|---|---|
| **缩放** | PPS（纯视图） | 不改任何时间值，只重绘 |
| **切割** | `trackT → ÷sp → foldMap → src` | 在 `src` 处把所在的绿区一分为二；**trackT 永在绿区，切不进红区** |
| **插入** | 加一个新 block | 新块自带 `keptRanges`（未剪=1 段 / 已剪=多段）；前缀和重算 |
| **替换** | 换新素材 | 见 4.1 |
| **变速** | 改 `speed_i` | `timelineDuration = baseDuration / speed`；后续块的 `T_i` 顺移 |
| **重排** | 拖动换序 | `blocks` 换序后前缀和重算；叠加 clip **留在原输出时刻**（见 §5 假设） |

### 4.1 替换（★ 本批新定）

**替换进来的素材是未波剪的**（皓哥 2026-10-05 22:38 确认）→ 新素材整段、无红可折。

```
L_lock = 被替换块的 timelineDuration（锁定的轨道时长）
L      = L_lock × speed（需要凑到的 baseDuration）

新素材时长 ≥ L  → keptRanges = [(0, L)]（裁到锁定值）→ 替换成功，块变为「单段裁剪态」
新素材时长 < L  → 拒绝替换，提示「素材太短」，保留原块
```

- 因此**替换不需要「重检红」**——新素材没波剪，只有裁剪。
- 替换后块仍是统一结构（单段 = 未波剪形态），其它操作不受影响。

## 5. 与录音轨 / 画中画轨的关系

| 项 | 规则 |
|---|---|
| 存储坐标系 | **输出时间（= trackT）**，主轨标记存源时间，**两者不要混** |
| 联动 | 默认开。**块 i 时长变化 Δ（波剪改绿区 / 变速都算）→ 该块之后的所有叠加 clip 平移 Δ**。Δ<0（主轨变短）时后续 clip 会撞上前面的 → **推到前一个末尾之后**（长度压短），同轨不允许重叠 |
| **重排时的 clip** | ⚠️ **假设（待皓哥确认）**：clip 锚定输出时间，重排后**留在原输出时刻、不跟着内容走**；超出新 TOTAL 被夹回 |
| 跨折叠区 | 输出时间连续 → 自然连续播放，不存在「跨过折叠区」问题 |
| 缩放 | 三轨同步重绘；录音轨波形、画中画缩略图随 PPS 重绘（纯视图） |
| 文字/字幕轨 | ❌ 不做（03:42 已删除） |

## 6. 关键不变量清单（供验证脚本断言）

| # | 不变量 | 说明 |
|---|---|---|
| **I1** | `T_0 == 0` 且 `T_{i+1} == T_i + timelineDuration_i` | 无缝、无重叠 |
| **I2** | 每块 `timelineDuration > ε` | 无零宽块 |
| **I3** | 每块 `keptRanges` 升序、不重叠、`0 ≤ a < b ≤ srcDuration` | 绿区合法 |
| **I4** | `baseDuration == Σ kept 长度`；`timelineDuration == baseDuration / speed` | 派生一致 |
| **I5** | `trackT → src` 的结果**必落在某段绿区内**（从不落红区） | 折叠正确性 |
| **I6** | 往返一致：`src → trackT → src == src`、`trackT → src → trackT == trackT`（ε 内） | 映射可逆 |
| **I7** | 块内 `trackT` 增大 → `src` 单调不减 | 无时序倒挂 |
| **I8** | 替换成功后：块为**单段**且 `timelineDuration == L_lock`（ε 内）；素材过短则**拒绝**、模型不变 | 替换对账 |
| **I9** | 变速后：块播放时长 `== baseDuration / speed`，且 I5/I6 仍成立 | 变速不影响折叠 |
| **I10** | `PPS` 变化不进入上述任何一条 | 缩放纯视图 |
| **I11** | 叠加 clip 升序、**不重叠**、落在 `[0, TOTAL]` 内 | 同轨不允许交叉 |
| **I12** | 联动：块 i 时长变化 Δ → 其后 clip 平移 Δ（被挤压时不得早于 Δ 平移后的位置） | 配音跟着画面走 |
