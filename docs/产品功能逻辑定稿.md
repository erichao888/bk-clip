## 0. 定位

**综合剪辑软件，主打卖点：自动识别气口。**
核心能力已实现（`BKDetector`：音频包络 + Otsu 阈值），是本 App 区别于剪映等的唯一差异化。

## 1. 术语表（统一，避免指代混乱）

| 术语 | 含义 |
|---|---|
| **波剪** | 「剪气口」＝「波形剪辑」的简称，**三者同一个东西** |
| **波形剪辑页 / 波剪页** | 针对**某一个片段**的气口标记子页面 |
| **气口** | 废话、停顿、呼吸等要删掉的片段（由算法自动识别 + 人工调整） |
| **红区** | 被标记为气口的区间（要删） |
| **绿区** | 保留区间（绿波形） |
| **分割线** | 只把片段划开的标记线，**不删任何内容** |
| **折叠** | 红区在主轨上收窄成一条线（宽 = 指针宽）的**呈现方式**，不是开关 |

## 2. 页面结构

```
起始页（草稿箱 / 导入）
   ↓
主编辑页（多片段主轨 + 叠加轨）
   ↓ 单击片段 → 悬浮菜单 → 点「波剪」
波形剪辑页（该片段专属）
   ↓ 返回
主编辑页（该片段以折叠形态显示）
```

## 3. 主编辑页

### 3.1 主轨：多片段

- **一次可导入多个视频片段**，主轨上一段一段排列（对齐剪映）
- **支持拖动排序**（片段顺序可调）
- 每个片段**独立记录**自己的红区与折叠状态

### 3.2 单击片段 → 悬浮菜单

- 蓝底胶囊 + 线条按钮（主色 `#2F6DF4`），锚定在片段正上方
- **6 个按钮**：替换 / 曲线 / 锁定 / 复制 / 删除 / **波剪**
- 「波剪」图标由皓哥另行设计

### 3.2.1 快捷方式：**双击片段 → 直接进波剪页**（皓哥 02:46）

- **双击**主轨上任一片段 = **跳过悬浮菜单，直接进入该片段的波剪页**
- **单击**仍然是弹悬浮菜单 —— 两者并存，各有分工

| 手势 | 结果 |
|---|---|
| 单击 | 弹悬浮菜单（6 按钮，含波剪） |
| **双击** | **直接进该片段的波剪页** |

> ⚠️ **实现要点（iOS 手势的固有坑）**：单击与双击共存时，
> **单击识别器必须 `require(toFail: 双击识别器)`**，
> 否则双击的第一下会先触发单击 → 弹出悬浮菜单，然后才进波剪页（闪一下菜单）。
> 悬浮菜单已展开时双击同样有效。

### 3.3 叠加轨（**2 条**）

> ⚠️ **03:42 删除文字轨**：主编辑页**不做字幕 / 文字轨**，
> 所有与文字、字幕相关的逻辑与操作**一律删除**（皓哥拍板）。
>
> **为什么不做的真实原因（03:49 皓哥实测结论，别再想加回来）**：
> 1. **字体排版**不好实现（字体、字号、描边、排版、多行折行都是坑）
> 2. **语音识别（ASR）**不好实现 —— 且本机实测 `faster-whisper` 模型根本拉不下来
>    （HuggingFace 与 hf-mirror 均 401），**语音转写这条路在当前环境不通**
> 3. 既然两头都难，**干脆不做** → 字幕交给剪映
>
> **既定工作流**：bk剪辑 负责剪气口 + 粗剪 + 画中画 + 录音 → **导出 MP4 → 进剪映加字幕**。

| 轨 | 内容 |
|---|---|
| **录音轨** | 边播边录的配音/旁白 |
| **画中画轨** | **视频 + 图片同一条轨**（不单独开图片轨） |

### 3.3.1 添加画中画：**默认铺满全屏**（03:02）+ **记住上次尺寸/位置**（03:21）

- 新添加的画中画，**在预览画面里直接铺满全屏**（归一化 rect = `0,0,1,1`）
- 想要小窗时，再由用户手动**缩小 / 拖动 / 旋转**
- **记住上次用过的尺寸 / 位置**：本次调过之后，**下次插入沿用上次的设置**
  —— 连续插几张图不用每张都调（皓哥 03:21 拍板）
- **理由**：剪映每插入一个画中画都是小窗，都得手动放大到全屏，「反人类」；
  咱们反过来 —— **默认全屏 + 记住习惯**，连续插入时零调整

> **实现**：
> ① 新建 PiP clip 时 `pipRect` 默认 = 全屏（`0,0,1,1`），不是小窗；
> ② 用户每次调整结束（拖动 / 缩放 / 旋转松手）把结果存进 `lastPipRect`，**随草稿落盘**；
> ③ 下次插入时若 `lastPipRect` 有值 → **用它**；没有（首次 / 新草稿）→ **退回全屏默认**。

- 两条轨都锚定**主轨输出时间**
- **联动**（默认开）：可勾选跟随的类型 = **画中画（含图片）/ 录音**（2 类）
- **磁吸**（默认开）：吸附锚点优先级 =
  ① 播放头 ② 折叠线 / 轨道接缝 ③ 保留区块边界 ④ 其它元素首尾 ⑤ 起点 0 与末端
  命中显示**蓝色竖线**（`#2F6DF4`）

### 3.4 其它

- **半屏余量**：所有轨道前后各留半屏空白，保证指针能从 0 开始、能到末尾结束
- **底部工具栏**：界面最下方，**可左右滑动**（解决图标多放不下）
- **录音**：「草稿静音」开关，**默认静音**（防外放串进麦克风）
- **不做**：切画中画/切主轨互换、锁定位置、层级、入场出场动画
- **❌ 不做字幕 / 文字 / 语音识别（ASR）** —— 字体排版与 ASR 都难实现，
  字幕在**导出后进剪映**加（见 3.3 的原因说明）

## 3.5 产品边界与工作流

```
bk剪辑 负责：
  多片段粗剪 · 自动剪气口（核心卖点）· 画中画 · 录音配音 · 导出 MP4

剪映 负责（导出之后）：
  字幕 / 文字包装 · 滤镜 · 转场 · 配乐 · 调速
```

**bk剪辑 不重复造剪映已经很强的部分**，只做它做不了的：**自动识别气口**。

## 4. 波形剪辑页（波剪页）— 每个片段专属

### 4.1 进入 / 退出

- **进入**：主编辑页单击片段 → 悬浮菜单 → 点「波剪」
- **退出**：**关闭 / 返回按钮**（⚠️ **没有「折叠开关」**）
- **可反复进入**修改（折叠可逆，不会折了就锁死）

### 4.2 页面内呈现

- 显示**完整的绿色波形轨道 + 上面的红区覆盖**
- ⚠️ **页面内红绿「不折叠」** —— 看到的是原始完整波形，便于标记与调整
- 进入即**自动识别本段气口**（跑 `BKDetector`）

### 4.3 操作

| 操作 | 说明 |
|---|---|
| 自动识别气口 | 进入即跑，红区自动覆盖识别出的气口 |
| 调整红区 | 手动拖红区边缘，改气口范围 |
| **红绿切换钮** | 切换当前选中区的红/绿 |
| **点视频区切换红绿** | 直接点某段区域切换其红绿状态 |
| **一键打分割线** | 在**白色指针（播放头）位置**打分割线 |
| 返回 | 回主轨，该片段**以折叠形态**显示 |

### 4.4 折叠的语义（重要）

> **折叠不是开关，是主轨的呈现方式。**
> 波剪页里标好红区 → 返回 → 主轨上该片段**就是折叠后的样子**（视觉变短）。
> 折叠量 = 该片段内所有红区之和；红区在主轨上收成**一条线**（宽度 = 指针宽）。
> 想改 → 再进波剪页调整，折叠实时更新（可反复）。

### 4.5 波剪页布局（2026-10-05 起草，UI 移交后降级为内部参考）

> 屏参照 iPhone 15 Pro Max：430 × 932pt，浅色系。自上而下分区：

| 区 | 高 | 内容与控件 |
|---|---|---|
| **A 顶部栏** | 44pt | 左：返回 chevron（SF 线图标，灰）→ 回主轨；中：片段标题「片段 2/5 · 00:48」；右：自动检测 eyedropper（蓝 `#2F6DF4`） |
| **B 状态行** | 20pt | 浅灰字：「已识别 N 段气口，保留 M 段」/「正在提取波形…」 |
| **C 时间刻度尺** | 11pt | 秒+帧（00:01 / 10f / 20f），贴波形上 |
| **D 主波形轨道** | ~360pt | 完整绿波形（`#24430F`）+ 粉红半透明红区（`#D6707A`@60%）+ 红区边界线（实心 `#D6707A`）；白色播放头竖线钉正中、内容左右滚；点区域切红绿、拖红区边缘改范围 |
| **E 概览条** | 30pt | 灰底小波形（`#4C5049`）+ 粉红气口块（60%）+ 橙色视窗框（导航 / 缩放定位） |
| **F 播放控制** | 40pt | 居中 play/pause（SF 线图标，蓝）；左右跳到相邻气口边界（可选） |

要点：
- 页面内红绿**不折叠**（见 §4.2）：看到原始完整波形，便于标记与调整。
- 播放头 = 白色竖线，钉屏幕正中，波形随播放 / 拖动左右滚；「打分割线」在播放头位置落刀（§4.3）。
- 红绿切换钮切「当前选中区」；点波形区亦可直切（§4.3）。
- 配色唯一归属 `BKTheme`；红区粉红、绿区深绿沿用 `docs/界面定稿.md` 色值，不引入新色。
- 退出 = 顶部栏返回（**无折叠开关**，见 §4.1 / §4.4）。

## 5. 导出

- **跳过所有红区**；成品时长 = 主轨各片段折叠后时长之和
- 三趟分离：
  1. **视频 pass**：主轨（各片段 keptRanges）+ 画中画合成
  2. **音频 pass**：主音频 + 录音轨
  3. **长度比对**：差值 ≤ 1 帧 + 余量 → 一致才合成 MP4
- 不一致 → 重做一轮（最多 1 次重试）；**两次仍不一致 → 报错并停止**（绝不无限重试、绝不崩）
