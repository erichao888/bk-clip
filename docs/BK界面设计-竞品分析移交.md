## 0. 背景
bk剪辑 v2.0 要重写 UI，核心模型是「**声音包络线红绿标记 + 红区折叠成指针宽**」。本任务聚焦**界面布局与视觉**。竞品对标某剪辑 App 的布局范式，已做像素级实测，并评估过雷同/维权风险。

## 1. 交互模型（已定稿）
- **红绿切换** = 界面独立按钮（不放轨道上），切当前选中区块 红 ⇄ 绿
- **点选片段** = 进编辑态：黄框 + 两端把手（‹ ›）+ 片段上方悬浮工具条
- **拖把手** = 改标记点，从折叠区露/收一截，轨道总长实时变
- **退出编辑** = 点空白处
- **底部工具栏** = 界面最下方，可**左右滑动**（解决图标多放不下）

## 2. 布局实测尺寸（iPhone 15 Pro Max，屏 430×932pt）

→ 这套直接作为 v2.0 布局基准。

## 3. 配色定稿
- 悬浮工具条主色：**`#2F6DF4` = RGB(47,109,244) = HSB(221°,81%,96%)**
- 形态：**蓝底胶囊 + 白色线条图标**（无白圆钮），与竞品「琥珀黄胶囊+白圆钮+填充图标」形成色/形/图标三重差异
- 颜色唯一归属 `BKTheme`：`static let accent = Color(hex: "#2F6DF4")`
- ⚠️ 待确认：选中**黄框**是否同步改蓝（保留黄框则「黄=选中 / 蓝=操作」双色语义成立）

## 4. 防雷同约束（重要，别抄回原样）
- ✅ 可借鉴：功能布局/交互范式（行业「必要场景」，不受保护）
- ❌ 须规避：竞品琥珀黄悬浮条**精确外观**、具体图标造型、其专属配色、已注册 GUI 外观专利、插画/吉祥物/动效
- 我方天然差异：声音包络折叠模型、**SF 线条图标**、底栏横滑、独立红绿按钮、折叠线=指针宽、蓝色悬浮条
- 总原则：**抄「思想」不抄「表达」**
